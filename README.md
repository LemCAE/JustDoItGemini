## 🌟 作品简介 (Overview)

**《AETHERIA · 浮光秘境》** 是一座悬浮于以太深空中的微缩晶棱生态瓶与交互式音画庭园。

在这里，昼夜潮汐随着现实世界无缝流转，或者由你随心拨动时空沙漏；古老悬岛上生长着感应天光的奇迹植物，水底游弋着具备反向运动学（Inverse Kinematics）脊椎骨骼的幻光锦鲤，风过时挂在悬岛石木上的五音编磬迎风自鸣。

作品集成 **100% 算法实时声学合成（Web Audio API）**，无需任何外部音频文件即可奏响空灵和弦、以太清风、琉璃细雨与 10Hz 阿尔法脑波双耳节拍。你可以在此播撒灵种、灌溉孕蕾、定格拍立得晨光照片、连缀深空远古星图，或向守护星灵汲取今日份的晨光神谕。

## 🚀 极简运行方式 (Quick Start)

本作品采用纯净原生的现代化 Web 前端架构，**零外部依赖、零 npm 构建、零网络 CDN 请求**，具备极致的稳健性与即开即用体验：

### 方式一：直接双击运行（最简便）
1. 在文件管理器中找到项目根目录下的 `index.html`。
2. 双击或拖拽至任意现代浏览器（Chrome、Edge、Safari、Firefox 等）即可直接畅享体验！

### 方式二：本地静态服务（推荐）
如果你偏好本地 HTTP 服务器环境，可打开终端并在当前目录执行：
```bash
# 使用 Python 启动
python -m http.server 8080

# 或使用 Node.js 快速启动
npx serve .
```
然后在浏览器中访问 `http://localhost:8080`。

## 🔮 核心系统与游玩指南 (Gameplay & Features)

### 1. 造物者工具箱 (Creator's Dock)
- 💧 **甘露宝珠 (Pipette)**：点击或拖拽在空气中凝聚露珠，浇灌土壤中的草木，或滴入水池溅起同心水纹与气泡。
- ☀️ **日华棱镜 (Sol Ray)**：在光标下方投射暖金天光神束，照耀冰冷的植物以加速其孕蕾盛放。
- 🍃 **灵风拂拂 (Wind Wand)**：在空气中划出气流轨迹，使草木枝条随风摇曳，并拨动悬挂的风铃自鸣。
- 🎵 **共振之音 (Harmonic Bell)**：敲击空灵的晶体磬钟，激发草木产生音律共鸣并释放音乐符号粒子。
- ✂️ **采撷星尘 (Scythe)**：采收盛开花瓣孕育的「星尘结晶（✨）」，用于在育种宝袋中解锁稀有植物。
- 🌱 **育种宝袋 (Seed Pouch)**：挑选物种并在悬岛上点击任意土壤或灵泉即可播种。

### 2. 六大奇迹灵植系统 (Botanical Ecosystem)
- **星辉幼蕨 (Filix Stellaris)**：夜间持续释放悬浮的淡蓝荧光孢子。
- **月影幽莲 (Nelumbo Lunaris)**：水生睡莲，白昼含苞，唯在月色与暮霞下盛展金蕊。
- **金芒垂柳 (Salix Aurum)**：修长柔韧的金色流光树，随风摇曳奏响清音。
- **时轮彩兰 (Orchis Temporis)**：与昼夜同频，晨曦泛粉、盛昼湛蓝、暮霞若金、长夜作紫。
- **晶棱微木 (Bonsai Crystallum)**：几何多面体水晶枝杈，折射梦幻光谱。
- **虹彩棱花 (Flos Iris)**：沐浴甘露后向四周激发绚烂彩虹粒子环。

### 3. 生态伙伴与灵性生物 (Living Fauna)
- **幻光锦鲤 (Spirit Koi)**：三尾不同花色（红白丹顶、星河幽蓝、流金辉耀）的锦鲤，拥有 6 节段柔性骨骼 Kinematics 算法，会自主游弋、觅食气泡并在水面受惊时迅疾避让。
- **星境守护灵 · 猎户 (Orion)**：栖息在古石门之上的星灵小兽。双眼会跟随光标转动，点击它会发出咕噜轻鸣并赠送温柔的星空箴言。
- **星海幻鳐 (Sky Ray)**：远古半透明浮空鳐鱼，在天际深处缓缓划过云海。

### 4. 算法音愈工坊 (Procedural Web Audio Engine)
- **多层环境声实时合成**：梦幻主弦乐 Pad、粉红噪声风声、低通滤波雨滴、昼鸟鸣啭与夜蛩低吟。
- **立体声空间声场 (Stereo Panning)**：根据你在生态瓶左侧或右侧的交互位置，音效动态空间分布。
- **10Hz 阿尔法双耳节拍 (Binaural Beats)**：内置科学调谐的双耳节拍，戴上耳机即可获得深度平静与专注。

### 5. 远古星图解谜与神恩 (Stargazer Astrolabe)
- 点击右侧「🔭」进入星象司南仪。
- 用星光引线连缀出「星海幻鳐座」、「时空沙漏座」与「原初之种座」。
- 连线完成时激发全屏流星雨与神圣和弦，并激活对应的**全岛神恩增益**（如草木水分流失减半、瞬间创生盛放等）。

### 6. 留影机拍立得工作室 (Polaroid Camera)
- 点击右侧「📷」定格当前生态瓶画面，生成带有精美纸质边框、真实日期时间戳与诗意笺语的拍立得照片。
- 支持四种艺术滤镜（清透原色、琥珀晨昏、青石夜影、梦境柔焦），并可一键下载高分辨率 PNG 留存。

### 7. 晨光星语与神谕 (The Oracle of Orion)
- 点击右侧「🔮」抽取今日的星辰指引神谕卡，根据晨昏时刻提供诗意箴言、行动建议、幸运频段与幸运色。
